# PACE ATLAS｜鐵人賽道分析與成績預估

支援自訂 226／113 公里賽道，以同一場過往比賽的分段成績，探索樂觀、中性、保守時間情境。完全靜態、無建置依賴，可直接由 GitHub Pages 託管。

## 功能

- 參考賽事游泳、自行車、跑步、T1、T2 時間。
- 比較原賽道與目標賽道的距離、爬升、風速、氣溫、浪況。
- 顯示分段、配速、總時間、賽道淨影響與可調情境幅度。
- 選用 GPX 匯入自行車距離、平滑後爬升與高度示意。
- 本機儲存／讀取／清除、CSV 匯出、列印報告。

## 模型

公式與限制完整揭露在網站「模型與假設」及 `model.js`。所有係數屬初始假設，尚未以選手結果進行實證校準。情境不代表百分位或信賴區間；跨距離推估對耐力訓練假設敏感。示範資料為虛構資料，不是官方賽道。

## 資料隱私

不傳送個人表單資料或 GPX，不使用追蹤碼、第三方執行程式或外部字型。只有按儲存才寫入 localStorage；GPX 原檔不保存。公開儲存庫中沒有選手個人資料。

## 開發與驗證

用任意靜態 HTTP server 開啟 `index.html`。模型驗證：`node model.test.js`。無 npm 安裝或建置步驟。
