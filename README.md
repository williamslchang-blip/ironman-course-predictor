# PACE ATLAS｜鐵人賽道比較、成績預估與賽前分析

公開網站：https://williamslchang-blip.github.io/ironman-course-predictor/

## 第二版功能

1. 輸入任何一場 51.5、113 或 226 比賽的場次名稱、游泳、T1、騎車、T2、跑步與總時間。分段必須來自同一場比賽，總時間差超過 2 秒時要求核對。
2. 輸入本次場次名稱、組別及實際距離；預估樂觀、中性、保守的五項分段、配速與總時間。本次 T1／T2 可以自訂，留白沿用過往。
3. 綜合比較兩場的浪況、淨水流、防寒衣、爬升、風曝露、技術性、路面、氣溫、濕度與曝曬；顯示等距離爬升密度、模型綜合時間調整率及各因素的時間影響。
4. 依目標賽道輸入產生游泳、自行車、跑步的特色、注意事項與一般執行建議。
5. 保留 GPX 自行車距離／平滑爬升匯入、本機儲存／讀取／清除、完整 CSV 與列印；支援舊版儲存資料遷移。

## 資料與模型界線

- 場次名稱只用於識別，沒有自動下載各場官方賽道的功能。兩場的實際路線、條件與資料連結需由使用者填入；示範場次與選手均為虛構。
-「已依官方手冊／GPX 填寫」是使用者自行標註，本站沒有獨立查驗來源。
- 完整公式在網站的「模型說明」與 model.js。各係數是尚未以選手成績校準的初始假設，不是 IRONMAN、World Triathlon 或 USA Triathlon 的官方公式。
- 跨 51.5／113／226 使用各分項距離的冪次換算。單場短距離無法驗證長距離耐力；近期體能、補給、設備與騎跑交互疲勞尚未個別建模。
- 綜合調整率表示目前選手輸入下的模型淨時間調整，不是客觀通用的賽道評分。各因素拆解按固定乘數順序產生，有順序依存性，非因果估計。
- 三種情境不是完賽機率、百分位或信賴區間。實際氣候、賽道與規則應依該屆公告確認。
- 解說框架參考 IRONMAN Race Factors to Consider 與 USA Triathlon 的配速文章，網站提供原始連結；沒有為未知路段編造具體路況或補給位置。

## 隱私與部署

純靜態 HTML / CSS / JavaScript，無執行階段套件、追蹤碼、外部字型或第三方執行程式。個人表單與 GPX 只在瀏覽器處理；按儲存才寫入 localStorage，GPX 原檔不保存。公開儲存庫不包含個人輸入。GitHub Pages 從 main 根目錄部署。

## 驗證

- node --check app.js
- node --check model.js
- node model.test.js
- node qa-dom.cjs

模型測試涵蓋九種距離轉換、相同條件重現原成績、總時間核對、因素加總、環境單調性、轉換區時間與條件式解說。

DOM 測試使用獨立安裝的 jsdom，不影響網站執行依賴。Windows 可先執行 npm install --prefix "%TEMP%/pace-atlas-qa" jsdom；其他環境可用 PACE_ATLAS_QA_ROOT 指向 jsdom 套件路徑。測試涵蓋啟動、表單、頁籤鍵盤操作、來源網址、儲存、舊版遷移與 GPX 正常／錯誤路徑。DOM 測試不能取代真實瀏覽器的視覺檢查。
